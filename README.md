This is the repository of the Network Analysis of Cuisine Relations project, the final project of group 845, for the DTU course 02805 - Social Graphs and Interactions.

The report explaining our findings can be found [here](https://github.com/DTUTWFriederich/Cuisine-Network-Project/documentation/Cuisine_Network_Project_Final_Report.pdf).

## Overview
```
├───code                  Contains the code used for data acquisition, ingredient list pruning and graph creation
├───data                  Contains for every cuisine on https://en.wikibooks.org/wiki/Category:Recipes_by_origin, a .csv and .json listing the ingredients each recipe uses. Also contains a .csv where all of this is combined into one file
├───documentation         Contains intermediate research findings, and the final report
├───output                Contains various network graphs, as well as filter reports
├───temp                  Contains files used for prototyping various graph layouts. NOT used in the final product
├───cuisine_data3.zip     Contains various code and data used for further analysis
└───cuisine_graphs.ipynb  Also contains further analyses done
```
